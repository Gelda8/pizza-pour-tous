# Pizza Pour Tous - Order Billing Program

C program that bills phone orders for the restaurant Pizza Pour Tous.

## Features
- Bill an order: customer phone and address, meals (3, 4, 8, 9, 13, 14), pizza type, quantity and payment method
- Calculates subtotal, GST (5%), QST (9.975%) and total
- Prints the invoice with a sequential number and the date and time
- Shows the total number of meals sold and the total sales amount
- Validates every input and asks again if it is invalid

## How to compile and run
gcc pizza_pour_tous_simple.c -o pizza
./pizza
